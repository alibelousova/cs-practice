Различие Git и GitHub: 
"Git" - программа на компьютере,которая отвечает за изменение кода и за сохранение правок
"GitHub" - сайт,куда загружается код из Git
"Использованные команды":
git status - показывает на каком этапе сейчас находится код
git diff - отвечает за какие-либо изменения в коде
git diff --staged - показывает разницу между изначальными изменениями и последним коммитом

Ветка - указатель на определнный коммит
