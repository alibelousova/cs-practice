чем отличается git diff от git show и git log, и что именно нашли log -S и blame:
git diff - делает сравнение между тем что мы только что написали и тем что было уже сохранено
git show - команада,показывающая всю инфу о коммите
git log - показывает список сделанных коммитов
log -S - находит те коммиты где код впервые появился или был удален
git blame - показывает текущий файл построчно с информацией автора и редакции
